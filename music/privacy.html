Privacy Policy

Sax Clip Scheduler is a personal tool used by a single person (its owner) to upload videos they created to their own TikTok account.

What data it handles

  • TikTok OAuth access and refresh tokens for the owner's account, plus the account's open_id and display name.
  • The owner's own video files and captions.

How it is stored and used

Tokens are stored only on the owner's computer, in a file readable only by the owner, and are used only to call TikTok's Content Posting API to upload the owner's videos. No data is sold, shared with third parties, or used for advertising or analytics. The tool does not access any other TikTok user's data.

Deletion

The owner can delete the local token file at any time and revoke access in TikTok's settings (Security & permissions → Apps and services).
